Atividade 1 – Teoria dos Conjuntos


Arquivo:

P1/atividade_01_conjuntos/conjuntos.py

Como executar:

Execute o arquivo conjuntos.py.

O programa solicitará os elementos dos conjuntos A e B.

Exemplo de entrada:

Digite os elementos do conjunto A:
1 2 3 4

Digite os elementos do conjunto B:
3 4 5 6

================================================


O programa apresenta:

• uniao;

• intersecao;

• diferenças;

• cardinalidades;

• conjunto das partes;

• partiçao;

• produto cartesiano;

• inclusao.

Atividade 2 – Divisibilidade, MDC e MMC

Arquivo:

P1/atividade_02_divisibilidade/divisibilidade.py


Como executar:

Execute o arquivo divisibilidade.py.

O programa solicitará dois números inteiros positivos.

Exemplo de entrada:

Digite o primeiro número:

Digite o segundo número:
18

O programa apresenta:

• MOD;
• passo a passo do Algoritmo de Euclides;

• MMC.
